# Process Engineering Decks

Presentations by **Joshua Sharpes, EIT** on equipment sizing and selection, heuristics, process safety, and engineering history. Companion material to the [technical portfolio](https://jsharpes-portfolio.netlify.app).

## How to use this repo

- **Read or search a deck:** every deck has a folder under `decks/` with a `README.md` holding its slide-by-slide text. Hand that file to your AI assistant and ask it questions, or use it to rebuild the material in your own format.
- **Get the original:** download the `.pptx` from the [decks-v1 release](https://github.com/joshuasharpes84-rgb/process-engineering-decks/releases/tag/decks-v1). Narrated decks play their audio in PowerPoint Slide Show mode. Large decks (200–700 MB) take a minute.
- **Ask on the site:** the portfolio's Ask button answers questions about any deck or tool.

## Interactive tools (one repo each)

Each tool repo holds the calculator as a standalone page, a README written for both engineers and their AI assistants (method, sources, validation, limits), and the project files behind it.

- [HEM Tailpipe Backpressure (API 521 §5.5.10)](https://github.com/joshuasharpes84-rgb/hem-tailpipe-backpressure): two-phase relief tailpipe built-up backpressure, omega method
- [Centrifugal Pump Sizing](https://github.com/joshuasharpes84-rgb/centrifugal-pump-sizing): single-stage radial pump: speed, NPSH, impeller/collector geometry, curve, thrust
- [Flow Meter Selector](https://github.com/joshuasharpes84-rgb/flow-meter-selector): rule-based ranking of 10 meter types from process conditions
- [Compressor Train Sizing](https://github.com/joshuasharpes84-rgb/compressor-train-sizing): type, efficiency, power, and cost-optimal stage count
- [Reactor Scale-Up](https://github.com/joshuasharpes84-rgb/reactor-scale-up): jacketed / packed-bed PFR: which limit binds first
- [EO Runaway Relief](https://github.com/joshuasharpes84-rgb/eo-runaway-relief): loss-of-mixing runaway in an EO ethoxylation reactor
- [Pressure Vessel Cost vs. Diameter](https://github.com/joshuasharpes84-rgb/pressure-vessel-cost): ASME VIII-1 wall, MAWP/MAWT, material screen, itemized installation
- [Cleaning Interval & Bundle Life](https://github.com/joshuasharpes84-rgb/hx-cleaning-interval): CaCO3-scaling cooler on TIC: valve-saturation trigger, cost-optimal interval, pitting-limited bundle life

For engineering study. Verify against current codes and standards before use in design.
